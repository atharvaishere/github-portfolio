# 🌐 Atharva's Personal Portfolio Website

[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/CSS)

A modern, highly responsive portfolio website designed to showcase my software engineering journey, GitHub projects, and technical skills. Built from the ground up using **HTML5**, **CSS3**, and **Bootstrap 5**, it features a sleek dark-themed UI and seamless animations.

## ✨ Key Features

- **Sleek Dark Theme:** Professional dark mode aesthetics with vibrant gradient accents.
- **Fully Responsive:** Mobile-first design that adapts flawlessly to desktop, tablet, and smartphone screens.
- **Dynamic Projects Showcase:** Interactive grid layout displaying highlighted projects with direct GitHub and live demo links.
- **Smooth Animations:** Subtle hover states and smooth scrolling for an enhanced user experience.
- **Fast & Optimized:** Leverages Bootstrap's grid system and FontAwesome icons over CDN for lightning-fast load times.

## 🗂️ Core Sections

1. **Hero Section:** Eye-catching introduction with direct calls to action.
2. **About Me:** Personal biography detailing my MSc in Software Engineering and industry experience.
3. **Skills Matrix:** Visual display of my technical stack (Python, JavaScript, React, AWS, Docker, etc.).
4. **Projects Grid:** Featured repositories with embedded tech stack badges.
5. **Contact:** Readily available links for networking and collaboration.

## 🚀 Live Demo & Deployment

This project is fully structured for GitHub Pages deployment. 
To view it locally:
1. Clone this repository: `git clone https://github.com/atharvaishere/github-portfolio.git`
2. Open `index.html` in any modern web browser.
